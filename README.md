# ecommerce-task-cedcoss
Abandoned Cart Reminder UI with Send Reminder button
CartSaver is a frontend-only abandoned cart recovery dashboard built with plain HTML, CSS, and vanilla JavaScript. It uses a "Lost and Found Center" concept where abandoned shopping carts are treated as lost items waiting to be recovered. The dashboard shows six customer carts with details like customer name, email, items left behind, cart value, and how long ago the cart was abandoned. Each cart has an urgency level (high, medium, or low) shown through color-coded badges and a thin strip at the top of each card. There is a stats bar at the top that shows total lost carts, recoverable revenue, rescues sent, and carts still waiting. When you click "Send Rescue Email" on any card, the button disables itself, the card dims slightly, a green pulse animation plays, a toast notification slides up from the bottom right corner, and the stats bar updates automatically. You can also filter cards by urgency level using the filter buttons. Below the dashboard there is a full email preview section that looks like a real marketing email, complete with a dark branded header, an itemized cart list, a discount code block with the code SAVE15, an urgency warning, and a complete purchase button.

To run the project, download all three files (index.html, style.css, and script.js) into the same folder on your computer. Then open index.html in any modern browser like Chrome, Firefox, or Edge. No installation, no server, no build step, no internet connection needed. Everything runs directly in the browser.

The project was built using only three things. HTML for the page structure and content, CSS for all the styling including layout, colors, animations, and responsive design, and vanilla JavaScript for the interactive features like rendering the cart cards from data, handling the send button logic, updating the stats, filtering cards, and showing the toast notification. No frameworks, no libraries, no external dependencies of any kind were used.
